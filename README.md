# README

## はじめに

開発サーバを起動します。

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスし、正常に起動できているか確認します。
※[http://localhost:3000/games](http://localhost:3000/games) にリダイレクトします。

---

## GitHub Codespaces を使用する場合

ローカル環境の構築が難しい場合は、GitHub Codespaces を使用して開発を行うことができます。

### 1. GitHub アカウントの作成

GitHub アカウントをお持ちでない方は、以下の手順でアカウントを作成してください。

1. [https://github.com](https://github.com) にアクセス
2. 「Sign up」をクリック
3. メールアドレス、パスワード、ユーザー名を入力してアカウントを作成
4. メールアドレスの確認を完了

### 2. Codespaces を開く

1. このリポジトリのページにアクセス
2. 緑色の「Code」ボタンをクリック
3. 「Codespaces」タブを選択
4. 「Create codespace on main」をクリック

Codespaces が起動するまで数分お待ちください。

### 3. 依存パッケージのインストールと起動

Codespaces が起動したら、ターミナルで以下のコマンドを実行します。

```bash
npm i
```

インストールが完了したら、開発サーバーを起動します。

```bash
npm run dev
```

### 4. ブラウザで開く

開発サーバーが起動すると、画面右下に「ポート 3000 で実行中のアプリケーションを開く」というポップアップが表示されます。「ブラウザで開く」をクリックしてください。

ポップアップが表示されない場合は、以下の手順で開くことができます。

1. 画面下部の「PORTS」タブをクリック
2. ポート `3000` の行を確認
3. 「Open in Browser」アイコン（地球のマーク）をクリック

### 5. ファイルのダウンロード（提出時）

作成したプレイヤープログラムを提出する際は、以下の手順でファイルをダウンロードしてください。

1. 左側のファイルエクスプローラーで `src/services/players/{チーム名}/index.ts`（または `index.js`）を右クリック
2. 「Download」を選択
3. ダウンロードされたファイルを提出

---

## 重要: コミット禁止

**プログラムが他のチームに閲覧されないように、絶対にコミット（git commit）やプッシュ（git push）を行わないでください。**

Codespaces 上で作成したコードは、コミットしない限り他の人には見えません。提出時は上記の「ファイルのダウンロード」の手順に従って、ファイルを直接ダウンロードして提出してください。

誤ってコミットしてしまった場合は、すぐに運営にお知らせください。
